## 5.15.0 — ดึงเอกสารครบทุกหน้า · รวมทุก PO · ตารางสินค้าจับคู่ใบรับ · ปรับข้อมูลเมื่อผูกใบรับ (2026-11-02)

### เปลี่ยนอะไร
- **ดึงเอกสารครบทุกหน้า (fetchAllDocuments)**: `GET /api/documents` มีการแบ่งหน้า (default limit 200, max 500) แก้ไขให้วนลูปดึงทุกหน้าจนครบยอด `total` เพื่อให้คิวตรวจสอบ, การ์ด KPI, และการ polling ใน LiveContext เห็นเอกสารทั้งหมดไม่หลุดหน้าที่เกิน 200/500
- **รวมทุก PO (Multi-PO)**: 1 ใบรับอาจครอบคลุมหลาย PO ของผู้ขายรายเดียวกัน → รวบรวม PO ทั้งหมดโดยไม่ซ้ำ (de-duplicated list) แสดง PO แรกพร้อมป้าย `+N` และ hover เพื่อดูรายการเต็ม
- **ตารางรายการสินค้า (InvoiceDetailPane)**: คอลัมน์ใบรับอ่านผลการจับคู่จาก Engine (`gr_line`, `gr_qty`, `gr_price`) แทนคอลัมน์ PO เดิมที่ว่าง พร้อมแสดงแจ้งเตือนกรณีราคาหรือจำนวนไม่ตรงกับใบรับ และปรับ CSS ตารางให้กระชับพอดีกรอบ
- **ปรับข้อมูลอัตโนมัติเมื่อผูกใบรับ (bind-receipt)**: ใช้เลขที่ใบแจ้งหนี้จากใบรับที่ใช้ค้นหาเป็นหลัก พร้อมปรับข้อมูล Invoice, Supplier Tax ID, Buyer, ORG_ID, PO, Receiver ให้ตรงกับใบรับ และบันทึกประวัติ/Audit ระบุรายละเอียดการปรับข้อมูล
