  · ปิดได้ด้วย env `VIEW_AS_ACTIONS=off` (กลับเป็นอ่านอย่างเดียว 403 PREVIEW_READ_ONLY) · แถบเหลือง/ข้อความในตัวเลือกปรับตาม
- **เพิ่ม Oracle account ให้ EU** (ตารางผู้ใช้ + หน้าต่างเพิ่มผู้ใช้): ช่องค้นหาแนะนำชื่อ Receiver จากเอกสารจริง
  (`GET /api/users/receivers`, สิทธิ์ MAP) — ชื่อที่ต่างแค่ตัวพิมพ์/ช่องว่างรวมเป็นรายการเดียว (ใช้ตัวสะกดที่พบบ่อยสุด) ·
  แสดงจำนวนเอกสาร · บริษัท · ล่าสุด · "ผูกกับใครอยู่แล้ว"
  กันบั๊ก: ซ่อนชื่อที่ผู้ใช้มีอยู่แล้ว · คลิกเลือกไม่เพิ่มซ้ำ · **ไม่เพิ่มคำที่พิมพ์ค้างตอนคลิกที่อื่นอีกต่อไป** (เดิมเพิ่มทันที)
  — เพิ่มอัตโนมัติเฉพาะชื่อที่ตรงกับเอกสาร ที่เหลือค้างในช่องพร้อมคำเตือน · พิมพ์ชื่อใหม่เองได้ (มีคำเตือนให้ตรวจตัวสะกด) · ↑↓ Enter Esc
- **หน้า AP: คลิกเลขที่ใบแจ้งหนี้** → ไปหน้าที่เอกสารอยู่ + เลือก + **เปิด PDF ทางขวา**
  (Confirmed / Sent / Posted → เอกสารที่ปิดแล้ว กลุ่ม AP Flow · Import Failed → คิวตรวจสอบ ปรับตัวกรองให้เห็นเอง)
  เดิมกดแล้วไม่ไปไหน (เลือกเอกสารในคิวโดยไม่เปลี่ยนหน้า)
- **เอกสารที่ปิดแล้ว: ลิงก์ "ถูกแทนที่โดย / ซ้ำกับ"** (แถวตาราง + การ์ดสรุป) → เปิดเอกสารอ้างอิงพร้อม PDF ·
  ถ้าเอกสารนั้นยังเปิดอยู่ (เช่นฉบับใหม่เป็น Review) → ไปคิวตรวจสอบพร้อม PDF (เดิมขึ้นแค่ข้อความแจ้ง)
  · ตรรกะเปิดเอกสารใช้ร่วมกับ Ctrl K (`useOpenDocument`) — ที่เดียว
- **หน้า AP: ช่องค้นหา** (ตัวเดียวกับคิว มีปุ่ม "✦ ตัวอย่าง") ค้นได้ทุกแท็บ: เลขที่ · ผู้ขาย · PO · ใบรับ · Batch ·
  ข้อความจาก Oracle · ผู้ Confirm · วันที่ · ยอดเงิน · ตัวเลขบนการ์ดแท็บนับตามคำค้น

## 5.13.1 — PDF เลื่อนดูทุกหน้า · แปลภาษาอังกฤษส่วนที่ตกหล่น (2026-10-29)

### เปลี่ยนอะไร
- **PDF ในหน้าคิว (dock)**: แสดงทุกหน้าต่อกัน เลื่อน (scroll) ดูได้ทั้งไฟล์ · กรอบหลักฐานอยู่บนหน้าของตัวเอง ·
  วาดเฉพาะหน้าที่ใกล้จอ (เปิดไฟล์หลายหน้าไม่หน่วง) · แต่ละหน้ามีป้าย "n / N" มุมล่างขวา
  · ตัวเลื่อนหน้า (‹ Page n/N ›) = เลื่อนไปยังหน้านั้น และเปลี่ยนตามหน้าที่กำลังอ่านเมื่อ scroll
  · กดหลักฐาน (Page n / ชิปหลักฐาน / Alt+←→↑↓) → เลื่อนไปหน้านั้นแล้วเลื่อนต่อไปที่กรอบให้อยู่กลางจอ
  · ไฟล์ที่ไม่มี PDF (เอกสารจำลอง) ใช้แบบหน้าเดียวเหมือนเดิม · กฎ "รูปหน้าไม่ตรงกับ Engine = ไม่วาดกรอบ" ใช้รายหน้า
- **ตรวจ BBox (แท็บใหม่)**: แก้เลื่อนดูได้แค่หน้าจอเดียว (body ของแอปตั้ง overflow:hidden) → ตัวดูเลื่อนเองทั้งไฟล์ ·
  ป้าย "หน้า n / N · k กรอบ" เหนือทุกหน้า · แถบบนมีตัวเลือกไปหน้า (บอกหน้าที่มีกรอบ) + ‹ ›
- **English**: เพิ่ม `src/lib/i18n-en-extra.json` — ยอดรวมสุทธิ, ชื่อบริษัทในเครือ, หน้าเอกสารจำลอง, หน้า Login,
  ป้ายหน้า PDF และประโยคคงที่จาก Engine (เช่น "ฟิลด์บังคับอ่านไม่ได้หรือไม่ครบ: …", "บรรทัดที่ n (Invoice: …): …",
  ราคา/จำนวน/หน่วยไม่ตรงใบรับ, ที่อยู่/Tax ID ลูกค้า, ยอดก่อนภาษี ≠ ยอดใบรับ) · กติกา "<ป้ายที่รู้จัก>: <ข้อมูล>"
  แปลเฉพาะป้าย ข้อมูลคงเดิม · ยังเป็นไทย (ข้อมูล): ชื่อผู้ขาย, คำอธิบายสินค้า, เหตุผลแบบอิสระจาก AI ของ Engine
  · `npm run i18n:missing` อ่านทั้งสองไฟล์

## 5.13.0 — ภาษาไทย/English ทั้งแอป · บริษัท "?" มอบหมายได้ · sync บริษัทในเครือ · ยกเลิก Confirm · Matrix สิทธิ์ตามจริง · แก้กรอบโฟกัส Ctrl K · ระบบ patch/CI (2026-10-29)

### เปลี่ยนอะไร
- **ตั้งค่า › ตั้งค่าทั่วไป** (ทุกบทบาท, `/settings`): เลือกภาษา ไทย / English และธีม · เก็บต่อเบราว์เซอร์ (`aiva.lang`)
  English ครอบคลุม **ทุกหน้าจอ**: เมนู, Topbar, Ctrl K, คิว/KPI/ตาราง/ตัวกรองวันที่, รายละเอียดเอกสาร, ผูกใบรับ, AP, เอกสารที่ปิดแล้ว,
  RBAC/Matrix, Audit, ดูในมุมมอง, PDF viewer, กล่อง action/เหตุผล, toast และข้อความ error จาก server (~1,050 ข้อความ + 188 รูปแบบ)
  วิธี: พจนานุกรม `src/lib/i18n-en.json` แปลตอนแสดงผล (`src/lib/i18nDom.ts`) — แปลเฉพาะข้อความ UI ที่ตรงพจนานุกรม
  **ข้อมูลไม่ถูกแปล**: ชื่อผู้ขาย/ผู้รับ, เหตุผลที่บันทึกแล้ว, ผลตรวจจาก Engine/OCR, ข้อความใน PDF · ค่าที่ส่ง server ยังเป็นไทยเหมือนเดิม
  ตรวจข้อความที่ยังไม่มีคำแปล: `npm run i18n:missing`
- **บริษัท "?"** (ระบุบริษัทไม่ได้) มอบหมายให้ ACC/APR ได้จากหน้า "สิทธิ์และการเชื่อมบัญชี" (chip "? ไม่ระบุบริษัท" โทนเตือน)
  server รับ `?` ใน `POST /api/users` · สิทธิ์เห็นเอกสารใช้ `docScope` เดิม (ไม่มีกติกาใหม่)
- **Sync บริษัทในเครือ** บันทึกจริง: ตาราง `Company` (ใหม่) → โหลดตอน start และหลัง sync → การจับคู่บริษัทของเอกสาร
  (Tax ID / ORG_ID) ใช้ข้อมูลที่ sync · Tax ID ใหม่จาก Oracle = "รอตั้งรหัส" (ยังไม่จับคู่) จน ADM/SA ตั้งรหัสแล้วกดเปิดใช้
  · SA นำเข้าจาก JSON ได้ (`POST /api/oracle/sync-companies { companies: [...] }`) · `GET /api/companies` ให้ทุกหน้าจอใช้ชื่อเดียวกับ server
  · ไม่ลบบริษัท และไม่ทับชื่อไทย/ชื่อ OU เดิม · ORG_ID ที่ย้ายไปบริษัทจริงจะออกจาก "?" เอง
- **กล่องค้นหา Ctrl K**: แก้กรอบโฟกัสซ้อน 2 จุด (ช่องค้นหาล้นขอบบนกล่อง · ปุ่มหมวดถูกตัดครึ่ง) — ต้นเหตุคือกฎกลาง
  `:focus-visible{box-shadow…!important}` · ตอนนี้ช่องค้นหาแสดงโฟกัสเป็นเส้นใต้สี accent + ไอคอนเปลี่ยนสี, ปุ่มหมวด/รายการใช้กรอบด้านใน
- **ยกเลิก Confirm** (ผิดฉบับ): หน้า AP › แท็บ "รอส่ง" มีปุ่มแดง **"ยกเลิก Confirm"** ท้ายแต่ละแถว (ติดขอบขวา)
  ACC + APR (+ SA) กดได้ → กล่องยืนยันบอกผลชัดเจน (กลับคิวตรวจสอบ Review · ใบรับว่าง · Duplicate เดิมยังเป็น Duplicate)
  เลือกเหตุผล + หมายเหตุบังคับ · ทีละแถว (ไม่มี bulk) · ปุ่มปิดเมื่อแถวถูกติ๊กไว้ส่ง Batch หรือกำลังส่ง ·
  กันกดซ้ำ (ปุ่มล็อกระหว่างบันทึก, server เขียนแบบมีเงื่อนไข → ครั้งที่สองได้ 422) · ส่ง Batch ยังเป็นของหัวหน้าบัญชี (POST)
- **Matrix สิทธิ์ตามจริง**: ROLES เป็นตารางเดียวที่ UI, server และหน้า Matrix ใช้ — เลิกเช็กชื่อ role ในโค้ด
  · หน้า Matrix จัดกลุ่ม (ดูเอกสาร / คิวตรวจสอบ / ส่งจ่าย AP / กำกับดูแล) + คอลัมน์ "ปุ่ม/หน้า" และ "เงื่อนไข"
  · แก้ที่ไม่ตรงกัน: SA ตัดสิน Manual Review / UNRESOLVED / ส่ง Batch ได้แล้ว (เดิม Matrix ✓ แต่ server 403)
    · ADM ส่ง Batch / Unconfirm / ตัดสิน Manual Review ไม่ได้แล้ว (เดิม Matrix — แต่ server ยอม)
    · Return Import Failed ต้องมี RETURN_FAILED (APR/SA) · เพิ่มสิทธิ์ชื่อ BIND_RECEIPT (EU/ACC/APR/SA — คนเดิม)
    · ลบ DUP_OVERRIDE (ไม่มีส่วนไหนตรวจจริง)
  · หน้า AP: SA เห็นรายการแล้ว (เดิมกรองเฉพาะ ACC/APR) · แก้ hook order ของปุ่มส่ง Batch
  · กล่อง action ทุกตัว: กันกดซ้ำ + แจ้งเหตุผลเมื่อทำไม่ได้ (เดิมเงียบ)
- **ระบบ patch แบบ version + CI/CD**: `scripts/patch/*` (apply · verify ครั้งเดียว · rollback · make-patch · affected tests),
  `docs/change/CHANGELOG.md` ไฟล์เดียว, `.agent/AGENTS.md` + `PROJECT_MAP.md` ใหม่, `ci/gitlab-ci.yml` + `scripts/deploy/compose-deploy.sh`
